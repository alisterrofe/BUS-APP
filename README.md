# Bus Driver Card Game

A mobile-first, pass-the-phone Bus Driver card game designed for GitHub Pages and iPhone Safari.

## Included rules

- Seven-row bus: 1, 2, 3, 4, 3, 2, 1 cards.
- All cards begin face down.
- Choose one card from each row, starting at row 1 at the bottom.
- Cards 2–10 are safe. Ace, Jack, Queen and King end the turn.
- One shared 52-card deck is used across all players.
- Chosen cards are discarded and replaced from the reserve deck.
- If the bus cannot be refilled, the bus wins and the group penalty appears.
- First player to clear the bus three times wins the match.
- A round winner chooses another player for a one-turn rule: take a shot if they lose their next turn.
- Optional adaptive fairness assist gently favours safe replacement cards after repeated failed turns without creating or removing cards.
- Host controls can toggle fairness, start a fresh deck while keeping scores, or end the match.

## Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Open the GitHub Pages URL shown by GitHub.

## Install on iPhone

1. Open the GitHub Pages URL in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Launch Bus Driver from the new Home Screen icon.

The app works offline after it has been opened successfully once from the hosted HTTPS address.

## Responsible play

Use points or non-alcoholic forfeits when appropriate. Never pressure anyone to drink, and never drink and drive.
